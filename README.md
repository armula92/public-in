# PUBLIC-IN 퍼블릭인

도시의 필요한 순간에 공공가치를 꽂아 넣는 디자인.

민간 기업과 함께 만드는 팝업형 공공시설을 매개로, 공공가치를 높이는 디자인을 공공 영역에 실험하고 기록하는 애자일 거버넌스 실험실의 저장소이자 소개 사이트입니다.

- 사이트: https://www.armula.com/public-in/
- 운영: SPD Lab. 홍익대학교 공공디자인전공
- 상태: 2026 구상 단계. 사이트의 매체와 발매 계획은 논의용 구상이며 실제 설치 기록이 아닙니다.

이 저장소는 빌드된 정적 사이트만 담습니다. 원고와 빌드 스크립트는 작업 원본에서 관리합니다.
